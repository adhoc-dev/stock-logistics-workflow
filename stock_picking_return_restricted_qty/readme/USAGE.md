To use this module, you need to:

1.  Create an outgoing or an internal picking.
2.  Include one or more products with enough stock.
3.  Validate the picking.
4.  Click on **Return** and, in the return picking, try to set a quantity
    higher than the delivered one and see the warning message. The same
    warning is shown when validating a return with a higher done quantity.
5.  With the restriction enabled, **Return All** fills each line with the
    quantity that can still be returned.
